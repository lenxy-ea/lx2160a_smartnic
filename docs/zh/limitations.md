# 验证范围与限制

- 当前配置已有 PCIe3 未连接时的 Linux 启动验证。Gen3 x4 配置上限不代表
  实际协商结果，连接设备后的速率、宽度和吞吐量仍未验证。
- 源码构建成功只验证构建与打包接口，不代表新生成二进制已经通过硬件验收，
  也不代表具备生产可靠性。
- 热启动和复位可靠性仍需硬件验证；此前观察到的次级 CPU 启动停滞问题
  尚未解决。
- 默认记录实际构建时间。对含时间信息的组件进行受控复现，需要一致的源码、
  依赖版本、工具链和 `SOURCE_DATE_EPOCH`。不承诺完整 Debian rootfs 字节一致，
  构建会记录已安装软件包版本。
- NOR 哈希和清单用于完整性检查，不提供启动认证。
- 板载 EEPROM 不作为配置或身份存储。
- MC 和 DDR 训练固件是外部二进制依赖，其源码与许可边界独立于本项目原创工具。
- 构建命令和 CI 不执行目标安装、Flash 写入、重启或 PCIe 硬件验收。
